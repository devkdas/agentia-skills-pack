# User Story Template

Copy this template for every story so agents and reviewers get consistent
context. Keep it short and factual.

## Title

`<type>: <what changes> for <who>`

## Problem

What is broken or missing, and who feels it. Two or three sentences.

## Scope

Files, metadata types and environments in scope. Explicitly list what is out
of scope.

## Acceptance criteria

- [ ] Criterion one, observable and testable
- [ ] Criterion two, observable and testable

## Test plan

CRT job or suite ID covering this story, plus any manual checks.

## Rollout

Target environment and order: UAT first, then production with approval.
Link the Gov Guard approval code used for production.
