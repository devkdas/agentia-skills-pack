# Release Notes Template

Generate with the release agent, then review by hand before publishing.

```sh
agentia ai agent ask --agent release "Generate release notes for <story-id>"
```

## Released

Story IDs, target environment and date.

## Changes

Bullet per story, written for admins and users, not developers.

## Validation

Promotion checks passed, test job IDs with green results, approval codes.

## Risks and follow ups

Known limitations, deferred items, linked follow up stories.
